# HeroVerse

Automated English Christian YouTube channel (prayer videos), produced and published by GitHub Actions.

**Start with [`migration/SYSTEM.md`](migration/SYSTEM.md)** for the product and stages,
[`migration/STANDARD.md`](migration/STANDARD.md) for quality requirements, and
[`migration/OPERATIONS.md`](migration/OPERATIONS.md) for the execution map and status sources.
Historical tools are isolated under [`migration/archive/`](migration/archive/README.md);
they are not part of the active pipeline and are not runnable in place.

Never commit credentials, tokens, models, media or caches. Additional cost authorised: zero.
