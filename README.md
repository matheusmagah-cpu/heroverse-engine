# HeroVerse

Automated English YouTube channel `@heroverse74`: a KJV Bible series, story by story, with long videos and Shorts
(`migration/production/bible/SERIES.md`), produced and published by GitHub Actions.

The workflow is **mining → modeling and production → originality, intention and critique →
publication → mining again**, with live intelligence following every stage and the market.
Each stage delivers evidence that the next stage must accept; Shorts have their own production and review.

**Start with [`migration/SYSTEM.md`](migration/SYSTEM.md)** for the product and stages,
[`migration/STANDARD.md`](migration/STANDARD.md) for quality requirements, and
[`migration/OPERATIONS.md`](migration/OPERATIONS.md) for the execution map and status sources.
[`CLAUDE.md`](CLAUDE.md) holds the owner's fixed rules and the reading order.

Never commit credentials, tokens, models, media or caches. Additional cost authorised: zero.
