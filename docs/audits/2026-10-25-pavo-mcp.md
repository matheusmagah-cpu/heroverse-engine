## Refused or unconfirmed candidates

- P1: needs deeper review of the provider's price-lock semantics. The current guard rejects every
  observed nonzero, estimated, malformed or underflowing price before submission. An atomic upstream
  guarantee requires provider documentation or an explicit provider contract; the adapter does not
  claim it, and the observed zero-credit test does not establish permanent free access.
- P2: refused, existing mitigation. The socket watchdog interrupts internal chunk-header reads;
  the local socket-pair test exercises this path. The README explicitly limits the watchdog to the
  stream body rather than claiming one deadline for quote, creation and stream setup.
- P3: refused, claim correctness. Unknown acknowledgement returns the original job identifier,
  null submission certainty and a no-resubmission instruction. History lookup never creates a job.
- P4: refused, existing mitigation. The fixed-origin opener refuses redirects and errors cross the
  MCP boundary as fixed local codes. No secret values were opened or copied during the sweep.
- P5: refused, existing mitigation. Only manual dispatch on main enters the secret-bearing job;
  the PR job runs without credentials. The secret is an environment variable, not a command argument.
