## Hardening note

- H1 `captions_audit.repair` reads `root / item["manifest"]` with no check that the path stays inside the
  repository. The plan is committed only through a reviewed PR, and the ledger-key binding refuses any manifest
  that is not a published video's own. A path outside the repository is therefore not exploitable as things
  stand. A containment check (`resolve()` under the repository root) would make this explicit.

H1 is recorded here, not fixed: it needs its own PR.
