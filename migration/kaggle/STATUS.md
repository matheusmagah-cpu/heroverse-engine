# Kaggle: not used for the monetized channel (decision 2026-10-17)

Kaggle's terms limit use of the Services to "internal, personal, non-commercial purposes", as quoted in the forum thread kaggle.com/discussions/general/272074. Kaggle's terms page itself could not be fetched directly to confirm the wording. A monetized YouTube channel is a commercial purpose. Using Kaggle for it risks losing the account mid-plan, which would mean guaranteed rework.

- **Kernels and datasets:** no new ones are created for HeroVerse production. The pilot-002 production kernel launched on 2026-10-17 is not collected, and its output is not used.
- **Images already in the release** (generated on Kaggle on 2026-10-17): SDXL base 1.0 outputs under CreativeML Open RAIL++-M. The model licence governs these outputs. They stay in use unless the owner decides otherwise.
- **Replacements:**
  - image generation: Cloudflare Workers AI, FLUX.1 schnell (Apache-2.0), on the free daily allocation;
  - rendering: GitHub Actions.
