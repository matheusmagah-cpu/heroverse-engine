Portable Blender render bundle — no external assets or credentials.

Requirements: Blender 4.3.2 Linux, working headless EGL/OpenGL 4.3+ context (Mesa software rendering is sufficient), and a writable output/cache directory. Blender includes its own Python and mathutils; there are no pip dependencies. All characters, materials, props, animation and cameras are generated by the two Python files. No font, image, texture, audio, repository or network access is required for rendering.

A render chunk is an independent local command. Examples:
RENDER_OUT=/work/output blender -b -t 8 --python production.py -- master 0 100
RENDER_OUT=/work/output blender -b -t 8 --python production.py -- vertical 0 100

Master bounds are frame indices, inclusive start / exclusive end. Vertical bounds index the sorted unique_times list in short-frame-maps.json. Native vertical frames are rendered from their own fitted 3D camera, not cropped or enlarged from the landscape output. Every output is deterministic for the same Blender build and settings. Run one chunk as a compatibility test before distributing the matrix.

Download/merge hd-frames/*.png and vertical-frames/*.png without renaming. Verify all 1,520 master frames and the manifest's unique vertical frames are present, decodable and have exactly the declared dimensions. Use the ordered short1/short2 time arrays to select the vertical frames. Stitch locally at 10 unique fps, export at 30 fps by frame repetition, and add approved audio/subtitles/CTA in final editing. The frame-map timestamps are source-story times, not output indices.

The included per-chunk runtime estimates are measured on the current 9-CPU environment, not a guarantee for another runner. GitHub runner speed, graphics compatibility, concurrency, quota, costs and storage limits are not verified by this bundle. It has not been committed, uploaded to a repository, or dispatched.
